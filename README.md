# NoteObjex

NoteObjex is a minimalist iOS app built in **Objective-C** using **UIKit** and a strict **MVC architecture**.

## Purpose

The project is designed to deeply understand and practice:
- Objective-C syntax and semantics
- UIKit without Storyboards or SwiftUI
- Classic Apple design patterns
- Memory management under ARC
- File-based persistence

## Architecture

- MVC (Model–View–Controller)
- No third-party dependencies
- No Interface Builder
- Programmatic Auto Layout

## Technical Stack

- Language: Objective-C
- Frameworks: UIKit, Foundation
- Persistence: plist files via `NSFileManager`
- Navigation: `UINavigationController`
- Communication: Delegation pattern

## Key Concepts Covered

- UIViewController lifecycle
- Delegates and protocols
- Manual layout with Auto Layout
- Data modeling with NSObject
- Separation of concerns
- Apple-style project organization

## Project Structure

- App: AppDelegate, SceneDelegate
- Models: Core data structures
- Controllers: View controllers
- Views: Custom UI components
- Persistence: Local data storage
- Resources: Assets and launch screen

## Goal

To be fully capable of reading, maintaining, and extending real-world Objective-C codebases used in Apple platforms.
